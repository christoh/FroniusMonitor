# Plans

## Instructions
- When asked to create a plan create a new plan with no further instructions, create a document *-plan.md. The document should be empty except an aedequate title. Also create a virtual directory in "Solution Items" called "Plans" and place the plan document in that directory.
  - The human developer will write the plan.
  - When asked to modify or delete the plan do so. Also delete the plan document from the .slnx file.
- If you receive specific instructions how to create a plan, follow these instructions.
- When you operate in plan mode, behave normally and create a plan
